# Zac Game Arcade

This folder contains the arcade landing page, the Court Rally tennis game, and a link to a separate Basketball Arcade.

## Live games

### Tennis

https://tennisgame-3ff.pages.dev/

Play Court Rally locally by opening `court-rally/index.html`.

### Basketball Arcade

https://basketballgame-b9b.pages.dev/

## Included

- `index.html` – arcade landing page
- `court-rally/` – Court Rally tennis game

## Local use

Open `index.html` in a browser to play Court Rally or visit the separate Basketball Arcade.
